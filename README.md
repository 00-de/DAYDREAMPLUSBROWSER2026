# DayDream Mail 送信API セットアップ手順

DayDream Browser のメール機能で、実際にメールを送れるようにします。
ターミナルは使いません。すべて画面操作だけで完了します。

---

## これは何をするものか

DayDream Browser は Windows アプリなので、そのまま Resend の API キーを持たせると、
アプリを配布した相手にキーが渡ってしまいます。

そこで、この小さなプログラムを Vercel に置き、**アプリからはここを経由して送信**します。
キーは Vercel の中だけに保管されるので安全です。

```
DayDream Browser  →  Vercel（この関数）  →  Resend  →  相手のメールボックス
```

---

## 1. フォルダを作る

デスクトップなどに `ddmail-api` というフォルダを作り、次のとおりに配置してください。

```
ddmail-api/
├── package.json
├── vercel.json
├── .gitignore
├── api/
│   ├── send.js
│   └── unsubscribe.js
└── public/
    └── unsubscribe.html
```

`api` と `public` はフォルダです。名前を間違えると動きません。

> `.gitignore` は先頭にドットが付きます。表示されない場合は、エクスプローラーの
> 「表示」タブ →「隠しファイル」にチェックを入れてください。

---

## 2. Resend に登録する

1. https://resend.com にアクセスして無料登録
2. 左メニュー **Domains** → **Add Domain**
3. お持ちのドメインを入力（例：`daydreamplus.jp`）
4. 表示される DNS レコード（SPF / DKIM）を、ドメインを取得した会社の管理画面に登録
5. 緑の **Verified** になるまで待つ（数分〜数時間）
6. 左メニュー **API Keys** → **Create API Key** → キーをコピーして保管

> ⚠️ **ドメイン認証は必ず行ってください。**
> これを飛ばすと、送信は成功しても Gmail などで迷惑メール扱いになります。

無料枠は 月3,000通・1日100通 までです。

### ドメインをお持ちでない場合

Resend の `onboarding@resend.dev` を使えば、**自分宛てのテスト送信だけ**は可能です。
ただし他の人には送れません。本格運用には独自ドメインが必要です。

---

## 3. Vercel にデプロイする

1. https://vercel.com にログイン
2. **Add New** → **Project**
3. `ddmail-api` フォルダを**そのままドラッグ＆ドロップ**
4. Framework Preset は **Other**（自動検出のままで構いません）
5. **Deploy** をクリック

完了すると `https://ddmail-api-xxxx.vercel.app` のような URL が発行されます。
この URL を控えておいてください。

---

## 4. 環境変数を設定する

Vercel のプロジェクト画面 → **Settings** → **Environment Variables**

| Name | Value | 必要性 |
|---|---|---|
| `RESEND_API_KEY` | 手順2でコピーしたキー | **必須** |
| `DD_ACCESS_TOKEN` | 好きな合言葉（例：`daydream2026`） | **強く推奨** |
| `FROM_EMAIL` | `info@あなたのドメイン` | 配信停止通知に使用 |
| `ADMIN_EMAIL` | 通知を受け取るあなたのアドレス | 配信停止通知に使用 |
| `ALLOW_ORIGIN` | `*` | 任意 |

追加したら **Deployments** タブ → 最新の行の「…」→ **Redeploy** を押してください。
**環境変数は再デプロイしないと反映されません。**

> `DD_ACCESS_TOKEN` を設定しないと、URL を知った人が誰でもあなたの Resend 枠で
> メールを送れてしまいます。必ず設定してください。

---

## 5. DayDream Browser 側の設定

アプリを起動し、**メール タブ → 設定** で入力します。

| 項目 | 入力する内容 |
|---|---|
| 送信者名 | `DayDream➕` |
| 送信元メールアドレス | `info@あなたのドメイン`（手順2で認証したもの） |
| エンドポイントURL | `https://ddmail-api-xxxx.vercel.app/api/send?token=daydream2026` |
| 配信停止URL | `https://ddmail-api-xxxx.vercel.app/unsubscribe.html` |

**エンドポイントURLの末尾** `?token=` の後は、手順4で決めた合言葉です。

「設定を保存」を押すと、画面右上が **「本番送信モード」** に変わります。

---

## 6. テスト送信

いきなり全員に送らず、必ず自分宛てで確認してください。

1. **連絡先** タブで、自分のメールアドレスを1件だけ登録（区分は「友人」など）
2. **一斉配信** タブで、区分を絞って対象を自分だけにする
3. 件名と本文を入れて **一斉配信する**
4. 自分の受信箱に届けば成功です

迷惑メールフォルダも確認してください。そこに入る場合は、手順2の
ドメイン認証（SPF / DKIM）に不備があります。

---

## 送られるメールの見た目

本文は自動で HTML に整形されます。

- 上部に DayDream➕ のグラデーションのヘッダー
- 本文は行間を広げて読みやすく
- URL は自動でリンクになります
- 配信停止URLを設定していれば、末尾にリンクが付きます

文字だけの版も同時に送られるため、HTML を表示できない環境でも読めます。

---

## 配信停止のしくみ

利用者が配信停止ページで手続きすると、**あなたのアドレスに通知メールが届きます**。

その通知を見て、DayDream Browser の **連絡先** タブから、そのアドレスを
削除してください。手作業になりますが、確実です。

> ⚠️ 配信停止の手段を用意することは、**特定電子メール法により義務**です。
> 広告や宣伝を含むメールを送る場合は、必ず設定してください。

## トラブル対処

| 症状 | 原因と対処 |
|---|---|
| `RESEND_API_KEY が設定されていません` | 環境変数を追加後、Redeploy していない |
| `合言葉が違います` | エンドポイントURLの `?token=` が環境変数と不一致 |
| `domain is not verified` | 手順2のドメイン認証が未完了 |
| 送信は成功するが届かない | 迷惑メールフォルダを確認。SPF / DKIM の不備が大半 |
| 1日100通で止まる | Resend 無料枠の上限。有料プラン（月 $20〜）へ |
| アプリが「シミュレーション」のまま | 設定タブのエンドポイントURLが空欄 |

## 安全上の注意

- **`DD_ACCESS_TOKEN` は必ず設定してください。** 未設定だと第三者に悪用されます。
- 合言葉は URL に含まれるため、画面共有や配信では映さないようご注意ください。
- 宛先は1通ずつ個別に送信されるため、**受信者に他の人のアドレスは見えません**。
- 事故防止のため、1回の送信は 2,000 件までに制限しています。
